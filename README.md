# Al-business by Al-capilot

This repository contains the landing page for the Al-business platform.

## Local preview
Open `index.html` directly in a browser.

## Deployment
- Deploy this repo to GitHub Pages.
- Set branch to `main` and folder to `/root`.
- The page will call the Render API at:
  `https://al-business-multi-agent.onrender.com/api/chat`
